# Paper Reviews

Paper-by-paper reviews of the peer-reviewed GEO literature, read from the primary source (not summaries), mapped against `aiseo-audit`'s current factors and recommendations. Each review answers:

1. What evidence contradicts the research our framework cites?
2. What reproducibly increased LLM citations, how was it tested, and what were the results?
3. What tool changes does the evidence justify (with file-level targets)?
4. What is explicitly out of scope for that paper?
